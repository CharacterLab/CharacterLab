Character Lab

Characters drawn in code with WebGL2, no images at render time, and measured part by part against their reference sheets, so every change to a drawing can be scored before it is kept.

  • The labPick a character and a part: its reference sheet beside the live render, compare modes, the score, the face's expressions and the animation clips.
  • ScoresEvery variant of every character scored with the lab's metrics, in one table (also npm run lab -- score).
  • FilmstripsA clip's frames side by side (?clip=<id>; npm run lab -- film --clip=<id>).
  • Cel materialThe renderer's cel look on its own, with no character pack loaded.

The characters come as packs: the example character, Captain Kite, is in packs/captain-kite/. packs/README.md explains the pack format and how to load your own from another folder (lab.config.json).
