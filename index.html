Character Lab

Draw characters in code, and measure how close you got.

Every character here is drawn by WebGL code, never by pictures. The lab sets each drawing beside its reference sheet and scores it part by part, so you can tell whether a change helped.

Create a new character →

Start from one or more pictures. The lab finds the figure, makes a pack and opens it with its first score.

A hero in a flat cel style: 26 variants, expressions, poses, a rig and two animation clips, all in code.
