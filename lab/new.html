New character

Start a character from a picture

Give it a name and add its reference pictures. The lab finds the figure on each one and makes a pack: a placeholder drawing you then replace with the character in code, scored against these pictures.

1 Name

The id names its folder and its links; it follows the name until you change it.

2 Pictures

PNG, JPEG or WebP, on a plain background. The first is the front: a full-body view, nothing cropped. Add more views if you have them (up to 8). Drag the box, or its corners, to change the crop.
